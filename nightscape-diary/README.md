# 夜景日記 Nightscape Diary

いつもの帰り道で出会った、心に残る夜景と色を集める日記（PWA）。
卒業研究「日常生活における身近な夜景への意識を促すサービスの提案」のプロトタイプ。

## 技術構成

- ビルド不要のバニラ JavaScript（ES Modules）＋ CSS。外部ライブラリ・有料APIなし
- 保存：IndexedDB（写真は端末内に保存。サーバーには送られません）
- PWA：`manifest.webmanifest` ＋ `sw.js`（オフライン起動）
- 色の類似度：OKLab 色空間の距離（人の見え方に近い）

## 手元で動かす

```
python3 -m http.server 8000
```
→ ブラウザで http://localhost:8000 を開く（`file://` では動きません）。

## iPhone で使う（HTTPS で公開）

カメラ・Service Worker・ホーム画面追加には HTTPS が必要です。無料の方法：

**A. Netlify Drop（いちばん簡単）**
1. https://app.netlify.com/drop を開く
2. このフォルダ（index.html がある階層）をドラッグ＆ドロップ
3. 表示された https://〜.netlify.app を iPhone の Safari で開く

**B. GitHub Pages**
1. GitHub にリポジトリを作り、このフォルダの中身をアップロード
2. Settings → Pages → Branch: main / (root) を選んで保存
3. 数分後に表示される https://ユーザー名.github.io/リポジトリ名/ を開く

**ホーム画面に追加**：Safari の共有ボタン → 「ホーム画面に追加」。

## 調整のヒント

- 似た色の判定の厳しさ：`js/colors.js` の `SIMILAR_THRESHOLD`（小さいほど厳しい。既定 9）
- 保存する写真の大きさ：`js/image.js` の `MAX_SIDE`
- ファイルを更新して公開し直したら、`sw.js` の `VERSION` を変更すると確実に反映されます

## 写真の保存先

- 写真は日記（ブラウザ内）に保存します。
- 「その他 → 撮った写真をiPhoneにも保存する」をオンにすると、アプリで撮影した写真を保存したあとに「写真アプリにも保存」ボタンが出ます（共有画面の「画像を保存」で写真アプリへ）。
- Webアプリの仕組み上、写真アプリへの自動保存はできません。

## 注意

- データはブラウザの中にだけ保存されます。Safari の「履歴とWebサイトデータを消去」で消えるため、「その他 → バックアップを書き出す」をときどき使ってください。
- ホーム画面から起動したアプリと、Safari で開いたページは保存領域が別になります（iOS の仕様）。

## 天気・位置情報（v1.5）

- 天気は Open-Meteo（https://open-meteo.com 、無料・APIキー不要・非商用利用可）から取得します。
  `current`（今の天気・気温・雲量・降水量）と、前後の1時間ごとの降水量から「晴れ／くもり／雨／雨上がり」を決めます。
  時刻は `timezone=auto`（その地点の時刻）で受け取り、`current.time` と同じ時間の行を使います。
- 取得結果は1時間再利用します。通信できないときは、同じ日の3時間以内の結果だけを「◯時◯分に取得した情報」と明記して使います。
  それより古い／ないときは「天気を取得できませんでした」と表示し、手紙は天気に触れずに届きます。
- 手動設定のときは「手動設定（実際の天気ではありません）」と表示します。
- 現在地は約10km単位（小数1桁）に丸めて端末内にだけ保存し、天気の取得時に Open-Meteo へ送るだけです。
- 日没・青い時間（太陽高度 −4〜−8°）・暗くなる時刻（−12°）は端末内で計算します（国立天文台の値と±2分程度）。
- 月齢は Meeus『Astronomical Algorithms』の簡略式で太陽と月の離角を求め、直前の新月の時刻から計算します（誤差およそ±0.1日）。
  月の出・月の入りの時刻は月齢からの概算で、実際とは30分以上ずれることがあります。

## 色名の判定（v1.5）

- データ：`js/colornames.js`（330色）
  - 日本の色名 195色：一般に使われている伝統色名・慣用色名。HEX値は本アプリが色見本として作成した近似値です（JIS規格の公式値ではありません。既存サイトのデータは複製していません）。
  - 外来語の色名 135色：W3C「CSS Color Module Level 4」の named colors の値（W3C Software and Document License）にカタカナ表記を付けたもの。
  - データ全体は MIT License（Copyright (c) 2026 夜景日記 / Nightscape Diary）。著作権表示はファイル冒頭にあります。
- 判定方法：採集した RGB を CIE Lab（D65）に変換し、全色名との CIEDE2000 色差が最小のものを「近い色名」とします。
  色差が 6 を超えるときは「暗い／明るい／くすんだ／鮮やかな」を前に付けます。HEX・RGB は採集した値をそのまま保存・表示します。
- 自分で付けた呼び名（ニックネーム）があればそれを優先して表示し、自動の色名は「近い色名」として併記します。
- 色名データを更新したときは `COLOR_NAMES_VERSION` を上げると、起動時に保存済みの色の「自動の色名」だけを付け直します（HEX・番号・呼び名は変えません）。

## サンプル記録（v1.5.1）

- サンプルは制作者が撮影した夜景写真16枚（`samples/photos/`）。長辺1600pxに縮小し、位置情報などのメタデータは含めていません。色の加工はしていません。
- 写真に撮影日時の記録がなかったため、`date` は撮影順と季節から決めた仮の日時です。正しい日時が分かれば `samples.json` の `date` を直して `version` を上げてください。
- タイトル・メモ・タグは、写真に写っているものだけで書いています（写っていると確認できない月・雨などは入れていません）。
- 写真が読み込めないときは、アプリが描くイラストのサンプル（`js/samples.js`）に切り替わります。

## サンプル写真の登録

1. 写真を `samples/photos/` に置く（例：`lamp.jpg`。長辺1600px以下ならそのまま、それより大きければ縮小して保存されます。色は変えません）
2. `samples/samples.json` の該当する項目に `"photo": "photos/lamp.jpg"` を追加
   - 任意：`"date": "2026-10-03T21:40"`（撮影日時）、`"credit": "撮影：◯◯"`、`"colors": [{"x":0.42,"y":0.61}]`（色を取る位置、0〜1）
3. いちばん上の `"version"` を 1 つ上げる
→ 次に開いたとき、サンプルだけが入れ替わります。自分の記録には触れません。サンプルを削除済みの人には再表示されません。

## 更新の反映

- `sw.js` の `VERSION` を上げて公開すると、開いているアプリにも新しい版が届き、撮影・入力中でなければ自動で読み込み直します。
- Service Worker はファイルを取りに行くとき、ブラウザの HTTP キャッシュを使わずにサーバーへ確認します（古いファイルが残らないように）。

## 天気の取得について（v1.1・旧版の説明）

- 天気は Open-Meteo（https://open-meteo.com 、無料・APIキー不要・非商用利用可）から1時間ごとに取得します。
  今の天気・3時間以内の雨・8時間以内に降った雨（＝雨上がり）・雲量から、手紙を選びます。
- 日没・青い時間（太陽高度 −4〜−8°）・暗くなる時刻（−12°）・月齢は端末内で計算します（目安）。
- 「その他 → 今夜の空 → 天気：手動で設定」にすると、選んだ天気で手紙が書かれます（実験・デモ用）。
- 手紙の文面は js/letters.js の `build(s)` で、`s.t.sunset`（日没）`s.t.blue`（青い時間）`s.moon` などを差し込んで作っています。
